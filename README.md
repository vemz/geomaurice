# Observatoire Résilience Côtière - Maurice 🌊

Carte interactive visualisant les données de résilience côtière pour l'Île Maurice et Rodrigues. Ce projet combine des données officielles sur la pauvreté, les inondations, les risques côtiers, l'énergie renouvelable et l'historique des crues.

## 🎯 Fonctionnalités

- **Carte interactive** (Leaflet.js) avec calques thématiques activables
- **Visualisations statistiques** (Chart.js) : distribution de la pauvreté, tendance des inondations
- **Analyses contextuelles** : explications détaillées sur les enjeux socio-environnementaux
- **Design moderne** : interface sombre avec effets glassmorphism

## 📂 Structure du Projet

- `index.html` - Page principale de l'application
- `style.css` - Styles CSS (design glassmorphism, responsive)
- `app.js` - Logique JavaScript (carte Leaflet, graphiques Chart.js, interactivité)
- `sources.md` - Documentation complète des sources de données

## 🚀 Lancement

Ouvrez simplement `index.html` dans votre navigateur web (aucune installation requise).

## 📊 Sources de Données

Ce projet utilise des données provenant de sources officielles :

- [GeoPortal Maurice](https://geoportal.govmu.org/#/) - Données géospatiales
- [Data.GovMU](https://data.govmu.org/dataset/) - Open Data national
- [Statistics Mauritius](https://statsmauritius.govmu.org/) - Statistiques officielles
- [Mauritius Meteorological Services](http://metservice.intnet.mu/) - Données climatiques
- **Rapport BRGM (2025)** - Étude des risques côtiers à Maurice et Rodrigues

Consultez [sources.md](sources.md) pour la liste complète et détaillée.

## 🛠️ Technologies

- [Leaflet.js](https://leafletjs.com/) - Cartographie interactive
- [Chart.js](https://www.chartjs.org/) - Graphiques et visualisations

- CSS3 (Glassmorphism, Flexbox, Grid)
